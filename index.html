📖 使用帮助
Emerald · 本地优先的 Markdown 文件管理器
🚀 快速上手
• 打开文件夹 = 进入工作区（标题栏「打开文件夹」或拖入文件夹）
• 左侧目录树点文件打开；Markdown 支持实时编辑（点块改原文，Esc 退出）
• 从资源管理器拖文件/文件夹进窗口即可打开
• 编辑后 Ctrl+S 保存；未保存的标签会显示 ●
⌨️ 常用快捷键
CtrlP 搜索文件 / 内容
CtrlShiftP 命令面板（所有功能入口）
CtrlS 保存当前文件
CtrlF 查找 / 替换
CtrlW 关闭当前标签
CtrlTab 循环切换标签
Esc 关闭浮层 / 退出块编辑
🧭 功能导览
• 分屏：编辑器标题栏 ▥ 按钮，或把左侧文件拖到渲染区右侧
• Git 面板：标题栏 Git 图标 —— 变更列表 / 差异 / 提交 / 推送
• 知识图谱：标题栏 🕸 图标 —— 笔记 [[双向链接]] 可视化
• AI 助手：标题栏 ✨ 图标 —— 配置 Key 后提问，自动附带当前笔记
• 标签：文件右键「编辑标签」，侧栏按标签过滤
• 反链：笔记标题栏 🔗 按钮，查看谁引用了本文档
• 大纲：右侧栏 📑 自动列出标题，点击跳转
• 批量重命名：命令面板搜「批量重命名」
• 插件：设置 → 插件商店，一键安装扩展
🧩 插件与 AI
• 插件是放入 用户目录\plugins\ 或 工作区\.emerald\plugins\ 的 .js 脚本，沙箱隔离运行
• 商店内置 Emoji / 日期 / 统计 / Frontmatter / 备份 五个插件，一键安装
• AI 需自带 API Key（DeepSeek / OpenAI / Ollama），Key 用系统安全存储加密，不出设备
